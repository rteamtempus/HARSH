Family UI System · v0.2 · Double Jaded

A quiet system,
with a warm spark.

A shared visual language for the mobile companion app and the living-room wall display. Built from the verdant greens of the "Double Jaded" palette — Obo, Reseda, and Sage carrying the surfaces — with burnt orange reserved for the moment of focus.

01 —

Principles

How decisions get made

"Surfaces recede. Type carries. Orange is the moment you look up."

i.

Green recedes, orange decides

Surfaces are deep green-charcoal — they hold the room. Burnt orange is reserved for one thing per screen: the action, the alert, the answer.

ii.

Warmth, never cold white

Text is cream, never #FFFFFF. Shadows are warm-tinted, not pure black. The system should feel like lamplight, not a hospital.

iii.

Two scales, one voice

The wall display uses the same colors and components as the phone — just larger type, fewer elements per screen, longer dwell times. Don't redesign; rescale.

iv.

Glanceable beats clever

The wall is seen from across the couch. If a number, name, or status can't be read at 8 feet, it's wrong.

Why #B8501F for the accent instead of Crave (#843D22)? Against the more saturated Obo Green surfaces, the source Crave can read a touch dim. The shifted hue keeps the family but earns its contrast. Crave returns at full strength in light mode, where the White Smoke canvas gives it all the headroom it needs.

03 —

Typography

Fraunces (display) · Inter Tight (UI)

A warm, slightly literary serif (Fraunces) for display and headings — it dresses the room. A neutral, modern sans (Inter Tight) for UI surfaces — it stays out of the way. Monospaced numerics (JetBrains Mono) for time, counts, and data so digits don't shift.

07 —

Light mode

For daylight, kitchen, or accessibility

Toggle the theme switch at the top of this page to see it. Light mode swaps the canvas to White Smoke (#EFF1ED), returns Crave to its full strength as the accent, and uses Obo Green as primary text with Reseda for secondary. Same components, same spacing — only the palette inverts.

Suggestion: leave the wall locked to dark (it lives next to a TV, brightness uniformity matters). Let the mobile app honor the OS-level prefers-color-scheme so it shifts naturally with daytime/evening use.

08 —

Implementation

Copy-paste tokens

Every token in this guide is a CSS custom property. Drop the :root and [data-theme="light"] blocks from this file's <style> tag into your Angular app's global stylesheet (or your SCSS partial). The [data-mode="wall"] modifier handles the rescale for the mounted display — same component code, just toggle the attribute at the app root.

Fonts load from Google Fonts via the <link> in the head — for production, self-host Fraunces and Inter Tight to control performance and avoid the FOUT.
