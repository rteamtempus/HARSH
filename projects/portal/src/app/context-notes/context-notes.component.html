Context notes

Short-lived context for the assistant — "big presentation Friday", "in-laws staying this week, don't mention X", "hard week, keep tone gentle". Tone-layer only: notes shape how the briefing reads, never auto-create tasks.

Every note expires automatically — maximum 30 days. After that it's deleted (not archived), so the assistant can't build a long-term emotional record.
